# ECOM · Carnet High Ticket

Espace d'apprentissage : lancer une boutique Shopify en dropshipping mid/high ticket en France, avec Google Ads.

- `index.html` : sommaire du cours (page d'accueil publiée)
- `MISSION.md` : pourquoi ce cours, et à quoi ressemble la réussite
- `lessons/` : une leçon interactive par semaine
- `reference/` : fiches imprimables
- `assets/` : feuille de style, quiz et simulateur partagés
- `RESOURCES.md` : sources officielles et communautés
- `learning-records/` : ce qui est acquis
- `NOTES.md` : notes de l'enseignant
